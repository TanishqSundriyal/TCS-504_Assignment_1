# TCS-504_Assignment_1
This is a console-based C++ application that models a cinema ticket booking workflow, built from a formal low-level design covering functional requirements, a noun-verb class analysis, a UML class diagram, and sequence diagrams for both booking and cancellation flows.  The system lets a customer browse currently playing movies, view showtimes for a selected film, and see a live seat map for a chosen show — each seat marked by its tier (Silver, Gold, Platinum) and availability. Pricing is calculated automatically based on seat tier, and payment is handled through an abstract base class supporting UPI, card, and cash. On successful payment, a ticket is generated with the booking ID, movie, showtime, seats, and total amount; bookings can later be cancelled, releasing the seats back to the pool.  Architecturally, the design separates concerns cleanly: domain entities (Movie, Seat, Screen, Cinema, Show) hold state, BookingService orchestrates the transaction, PriceCalculator and TicketPrinter handle single-purpose utility logic, and Payment is an abstract base class with a pure virtual pay(), extended by concrete payment methods — allowing new payment options to be added without touching existing booking logic. The design explicitly maps to SOLID principles (SRP, OCP, LSP, DIP) as justification for these boundaries.
